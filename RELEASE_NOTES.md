# telegram-agent-notify v0.1.0

The first public release of a small, dependency-free Telegram notification layer for AI coding agents.

Highlights:

- one concise completion message after a task finishes;
- interactive discovery of a Telegram group or forum topic, without manually finding IDs;
- a default destination plus per-project destinations;
- Codex CLI and Claude Code skills;
- safe token storage, HTML escaping, redacted network errors, and explicit-only file uploads;
- supported corporate HTTPS proxies through an explicit PEM CA bundle while keeping TLS verification enabled;
- Linux/macOS shell, Windows CMD, and PowerShell installation paths;
- automated tests on Ubuntu, macOS, and Windows.

See [README.md](README.md) for installation and configuration.
